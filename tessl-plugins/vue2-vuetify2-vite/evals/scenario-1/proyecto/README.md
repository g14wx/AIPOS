# Store POS

Point-of-sale system for a small store: product catalog and sales.

## Stack requested by the client

- Backend: Node.js + Express REST API in `backend/`, on http://localhost:3000, with every route under `/api`.
- Frontend: Vue 2 with Vuetify, calling the API with Axios. It goes in `frontend/`.
- Database: MySQL.

## Status

- `backend/`: stub with the health route. Product and sale routes are next.
- `frontend/`: not created yet.
