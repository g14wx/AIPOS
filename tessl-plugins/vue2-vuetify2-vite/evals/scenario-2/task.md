# Point-of-sale screen

The frontend in this repository already starts and talks to the backend through `src/api/`. The user asked:

> Build the point-of-sale screen and show it in the app. The cashier searches products by name or barcode and adds them to the current sale. Each line shows the product, quantity, price and subtotal. The cashier can change the price of a line and delete a line. Show the sale total and a button to register the sale, with a confirmation first. After registering, empty the sale and tell the cashier it worked, or why it failed.

You don't need to install dependencies or start the app. The files you write are what will be reviewed.
